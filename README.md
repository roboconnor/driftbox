# Driftbox

Driftbox is an offline-first, sample-based soundscape player for Raspberry Pi installations.

It plays prerecorded audio files in independent layers, using random selection and variable gaps to create an evolving soundscape. It is designed for unattended installations that may run for days without a monitor, keyboard, or network connection.

## Wicked Woods build

**Version 0.1** is the **Wicked Woods build**, developed for a Spraoi installation. October 2026.

It uses a curated library of prerecorded sounds organised into five layers:

| Layer | Folder | Role |
|---|---|---|
| Atmosphere | `bed` | Continuous environmental foundation |
| Birds | `birds` | Crows, ravens, and other bird sounds |
| Bowed piano | `bowed` | Haunting bowed-piano textures |
| Freaky piano | `piano` | Shorter, more unsettling piano events |
| Wolves | `wolves` | Wolf howls and related calls |

The soundscape is generated by scheduling sounds from these folders with variable gaps and gains. No audio is synthesised; all material is prerecorded.

## How it works

Driftbox has two playback modes.

### Single-loop mode

One specified audio file plays repeatedly.

```yaml
mode: single_loop

single_loop:
  file: bed/atmosphere_01.mp3
  gain: 0.8
```

### Generative layers mode

Each layer independently:

1. Selects an audio file at random from its folder.
2. Plays it.
3. Waits for a random interval between configured minimum and maximum gap values.
4. Selects another file.
5. Repeats.

Silence is produced by the scheduler, not by silent audio files.

## Wicked Woods configuration

The production configuration is:

```text
config/wicked_woods_birds_wolves.yaml
```

A starting configuration:

```yaml
soundscape: wicked_woods_birds_wolves
audio_root: audio
mpv_binary: mpv

mode: layers

layers:
  - name: atmosphere
    folder: bed
    min_gap_seconds: 2
    max_gap_seconds: 15
    max_concurrent: 2
    gain: 0.8

  - name: bowed_piano
    folder: bowed
    min_gap_seconds: 40
    max_gap_seconds: 140
    max_concurrent: 1
    gain: 0.5

  - name: freaky_piano
    folder: piano
    min_gap_seconds: 20
    max_gap_seconds: 80
    max_concurrent: 1
    gain: 0.65
  
  - name: birds
    folder: birds
    min_gap_seconds: 6
    max_gap_seconds: 25
    max_concurrent: 1
    gain: 0.7
  
  - name: wolves
    folder: wolves
    min_gap_seconds: 5
    max_gap_seconds: 35
    max_concurrent: 1
    gain: 0.7
```

The atmosphere layer is most active and may overlap with itself. Bird calls occur regularly, bowed piano provides longer haunting textures, freaky piano appears less often, and wolf howls are relatively rare high-impact events.

## Supported audio formats

Driftbox can play:

- MP3
- WAV
- FLAC
- OGG
- M4A
- AIFF

Audio files are not committed to the repository. Place them in local folders beneath `audio/`.

## Requirements

- Python 3.10 or later
- [mpv](https://mpv.io/)
- Raspberry Pi OS Lite, macOS, or Linux
- Local audio files

Install mpv on macOS:

```bash
brew install mpv
```

Install mpv on Raspberry Pi OS or Debian:

```bash
sudo apt update
sudo apt install -y mpv
```

## Installation

Clone the repository:

```bash
git clone [https://github.com/roboconnor/driftbox.git](https://github.com/roboconnor/driftbox.git)
cd driftbox
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install Driftbox:

```bash
pip install -e .
```

## Run locally

Run the Wicked Woods configuration:

```bash
python -m driftbox.main --config config/wicked_woods_birds_wolves.yaml
```

Then open:

```text
http://127.0.0.1:8000
```

For development with automatic reloading:

```bash
python -m driftbox.main --config config/wicked_woods_birds_wolves.yaml --reload
```

## Web interface

Driftbox includes a minimal local web interface.

It provides:

- Current playback status
- Active mpv processes
- Configuration editing
- Save and apply
- Restart playback
- Stop playback

API endpoints:

```text
GET  /api/status
GET  /api/config
POST /api/config
POST /api/restart
POST /api/stop
```

Example:

```bash
curl http://127.0.0.1:8000/api/status
```

## Raspberry Pi deployment

Driftbox is intended to run as a systemd service on a headless Raspberry Pi.

A typical deployment uses:

- Raspberry Pi OS Lite
- A local user account, for example `driftbox`
- The project installed at `/home/driftbox/driftbox`
- A virtual environment at `/home/driftbox/driftbox/.venv`
- The Wicked Woods configuration at `config/wicked_woods_birds_wolves.yaml`
- mpv installed through APT
- Avahi enabled for `driftbox.local` discovery when a network is available

Example systemd service:

```ini
[Unit]
Description=Driftbox soundscape player
After=multi-user.target

[Service]
Type=simple
User=driftbox
WorkingDirectory=/home/driftbox/driftbox
ExecStart=/home/driftbox/driftbox/.venv/bin/python -m driftbox.main --config /home/driftbox/driftbox/config/wicked_woods_birds_wolves.yaml --host 0.0.0.0 --port 8000
